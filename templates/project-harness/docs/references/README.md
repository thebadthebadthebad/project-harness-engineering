# references

이 디렉터리는 Evidence / Reference를 소유한다. 외부 자료, 조사 근거, 사례 요약처럼 프로젝트 판단에 참고한 자료를 보관한다.

## 책임

- 외부 문서 링크
- 조사한 사례 요약
- 참고한 engineering blog, tool documentation, repository 사례
- 결정이나 설계에 영향을 준 근거

## Out of Scope

references는 프로젝트의 최종 판단을 소유하지 않는다.

- 최종 목적과 범위는 `docs/INTENT.md`가 소유한다.
- 현재 구조는 `docs/DESIGN.md`가 소유한다.
- 결정 이유는 `docs/DECISIONS.md`가 소유한다.
- 현재 작업 상태는 `docs/WORK.md`가 소유한다.

## 작성 규칙

- 외부 자료를 그대로 길게 복사하지 않는다.
- 프로젝트에 필요한 관찰과 적용 가능성만 요약한다.
- 어떤 결정이나 설계에 영향을 줬는지 링크한다.
- 단순 북마크 목록으로 만들지 않는다.
