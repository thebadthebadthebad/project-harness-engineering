# DECISIONS

이 문서는 Decision Record를 소유한다. 현재 작업 상태는 `WORK.md`, 구조의 최신 상태는 `DESIGN.md`가 소유한다.

## 기록 형식

각 결정은 다음 형식을 사용한다.

```markdown
## YYYY-MM-DD: 결정 제목

Status: accepted | proposed | superseded

Decision:
...

Rationale:
...

Alternatives:
...

Consequences:
...
```
