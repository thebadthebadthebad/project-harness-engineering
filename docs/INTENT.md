# INTENT

이 문서는 이 저장소의 Project Intent를 소유한다. 현재 작업 상태, 세부 구조, 결정 이유는 이 문서의 책임이 아니다.

## 목적

이 저장소의 목적은 다양한 AI Agent 프로젝트에서 반복 사용할 수 있는 공용 프로젝트 하네스를 설계하고 구축하는 것이다.

여기서 공용 프로젝트 하네스는 특정 애플리케이션이나 모델 구현체가 아니라, agent가 장기간 프로젝트를 수행할 때 필요한 작업 규칙, 문서 구조, 컨텍스트 관리 방식, 템플릿, 검증 절차를 포함하는 재사용 가능한 기반 환경을 의미한다.

## 범위

- AI Agent 프로젝트에서 재사용 가능한 Repository Knowledge Model 설계
- agent가 최소한의 context로 필요한 문서를 찾을 수 있는 문서 ownership 구조 설계
- 공용 프로젝트 하네스 템플릿 작성
- 현재 저장소에 템플릿을 적용해 검증
- 향후 skills, hooks, rules, plugins, subagents, goal 관리 방식 등으로 확장 가능한 기반 마련

## Non-goals

- 특정 AI 모델, 서비스, 제품을 구현하지 않는다.
- 모든 possible tooling을 한 번에 구축하지 않는다.
- 특정 프레임워크나 언어에 강하게 종속되는 템플릿을 만들지 않는다.
- 문서를 많이 만드는 것을 목표로 하지 않는다.

## 성공 기준

- 다른 프로젝트에 복사해 사용할 수 있는 공용 하네스 템플릿이 존재한다.
- 각 문서가 소유하는 Knowledge Type이 명확하다.
- agent가 항상 읽어야 할 문서와 필요할 때만 읽을 문서를 구분할 수 있다.
- 현재 작업 상태와 장기 지식이 섞이지 않는다.
- 프로젝트가 성장해도 문서 중복과 역할 모호성이 최소화된다.
